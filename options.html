Opciones de PAGECHECK

La comprobación contra las listas de amenazas de Google (Safe Browsing) necesita una clave de API gratuita. Sin ella, el resto de comprobaciones funciona igual, pero esta queda pendiente.

  1. Entra en la consola de Google Cloud y crea un proyecto (o usa uno existente).
  2. Activa la API "Safe Browsing" para ese proyecto.
  3. Crea una clave de API y pégala aquí.

La clave se guarda solo en tu navegador (almacenamiento de Chrome) y se usa únicamente para consultar las páginas que analizas.
